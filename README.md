## Project Overview
This project implements customer segmentation using machine learning clustering techniques.

## Dataset Files
- `customer_info.csv` - Raw customer information data
- `customer_info_clean.csv` - Preprocessed customer data
- `customer_basket.csv` - Customer purchase data

## Notebooks
- `datapreprocessing_and_visualisation.ipynb` - Data cleaning, analysis, and visualisation 
- `customer_segmentation.ipynb` - Customer segmentation using clustering algorithms
- `targeted_promotions.ipynb` - Association rule creation and interpretation 

## Getting Started
1. Open the Jupyter notebooks in order:
   - First run `datapreprocessing_and_visualisation.ipynb`
   - Then `customer_segmentation.ipynb`
   - Finally `targeted_promotions.ipynb`
